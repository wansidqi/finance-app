# Finance App

Finance App is a personal finance and zakat tracking application. It helps users keep a clear view of their financial position by recording assets and liabilities, while also supporting zakat planning and tracking.

## What It Does

- Shows a dashboard for an overview of personal finances
- Records and manages assets such as savings, cash, or other valuable holdings
- Records and manages liabilities and outstanding obligations
- Tracks zakat progress and relevant payment information
- Supports Hijri date calculations and nisab checks for zakat-related workflows
- Provides local mobile data services alongside a backend API
